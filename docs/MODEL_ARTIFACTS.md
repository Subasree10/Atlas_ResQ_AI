## Checkpoint Loading Protocol

The `.pt` files contain **state_dict only** (not a full serialised model). The correct loading procedure is:

```python
from torchvision import models
import torch.nn as nn
import torch

# 1. Reconstruct architecture
model = models.efficientnet_b0(weights=models.EfficientNet_B0_Weights.IMAGENET1K_V1)
model.classifier = nn.Sequential(
    nn.Dropout(p=0.3, inplace=True),
    nn.Linear(1280, 1),  # single binary logit
)

# 2. Load state_dict
state_dict = torch.load("models/resqvision_efficientnet_b0.pt", map_location="cpu")
model.load_state_dict(state_dict, strict=True)
model.eval()
```

> **CRITICAL**: Do NOT `torch.load()` expecting a complete model object. It is a state_dict.

## Scientific Limitations

AtlasResQ AI detects **visible damage patterns** in satellite imagery.

It does **NOT** establish:
- Survivors or casualties
- Building occupancy
- Confirmed rescue requirements
- Exact building boundaries (Grad-CAM is attention visualisation, not segmentation)

All outputs are **preliminary AI-estimated assessments** requiring human verification.
